# 编导 · dsh-plugin-biandao

DSH 插件：把「编导」短视频编导技能包装进 DSH（DeepSeek Harness），注册为内置技能，在对话里随叫随用，并附一个「编导」标签页做模块地图。

方法论来源：最强师傅 V3.0（非官方方法蒸馏：最强编导的选题/爆款方法 + 马师傅的文案方法——卖点五问、痛点—爽点—痒点、改句子），技能本体（`zuiqiang-shifu-v3`）共 1 个总路由 + 17 个模块，版本 3.0.0，维护者曙光，MIT 许可，详见 `skills/zuiqiang-shifu-v3/NOTICE.md`。

## 能力

- **选题**：选题五步、离线出题（默认不联网，用户要求才搜）
- **爆款口播**：爆款工厂四条件诊断、负债—还利结构、完播五法
- **标题 / 开头 / 深度稿**：标题实验室、开头选择器、深度实验室
- **IP 与增长**：IP 故事、起号、涨粉引擎、变现、避坑指南
- **马师傅三件套**：改句子（copy-craft）、痛点转化、痒点营销——卖货文案专用
- **交付纪律**：每次只选一个唯一 owner 模块、最多接一个增强；步骤不跳步；交付前过 VOICE_RULES 去 AI 味终检，口播稿再做一遍真人润色

## 安装

### 方式一：DSH 桌面版粘贴仓库地址（推荐）

1. 打开 DSH → 侧栏「插件」→「添加插件」
2. 粘贴仓库地址：

```
https://github.com/hbycwzm001/dsh-plugin-biandao
```

3. 点安装，装完按提示重启 DSH

### 方式二：插件市场索引源

1. DSH → 插件 → 发现 → 添加索引源，粘贴：

```
https://hbycwzm001.github.io/dsh-plugin-biandao/market/index.json
```

2. 搜索「最强师傅」→ 安装 → 重启 DSH

## 使用

装好后不需要任何配置，在对话里直接说你要什么，技能会按需求自动触发：

- 「给我出几个选题，方向是职场口播」
- 「这条口播稿帮我看看能不能爆」→ 爆款诊断
- 「帮我写一条 60 秒的口播，主题是……」
- 「这句话太空了，帮我改得像真人说的」→ 马师傅改句子
- 「这个产品卖点怎么讲」→ 卖点五问 / 痛点转化

普通闲聊、翻译和与内容创作无关的请求不会触发这个技能。

## 面板（「编导」标签页）

装好后，对话顶部会多一个「编导」标签页，它是这个技能的模块地图和提问入口：

- **顶部**：一句话说明 + 使用流程三步（先过选题 → 唯一负责人模块干活 → AI 味终检）
- **模块地图**：17 个模块按分组摆开——8 个主簇（选题/起号/爆款/IP故事/涨粉/变现/训练/避坑）、6 个窄模块（标题/开头/反差/深度/冲突利害/承诺—交付）、3 个马师傅模块（改句子/痛点转化/痒点营销）；每张卡片写明这个模块管什么，并配一句示例提问
- **「复制提问」按钮**：点一下把示例提问复制到剪贴板，粘贴到对话里发出去就能开工（宿主没有把文本直接发进对话的接口，所以用复制+粘贴这一步）

面板只是地图和入口，真正的活在对话里由技能干。

## 目录结构

```

├── package.json            # 插件声明（dsh.bundle.patch → cordis.patch.yml；dsh.client → client.js）
├── cordis.patch.yml        # 把技能提供者插入 DSH
├── src/
│   └── index.mjs           # Host 适配器：读 SKILL.md 并 ctx.skills.register() 注册
├── client.js               # 「编导」标签页：模块地图面板（复制提问入口）

│   └── zuiqiang-shifu-v3/  # 技能本体（原样打包，含 SKILL.md 总路由与 17 个模块）

│   └── index.json          # 生成的市场索引（发版时按新 commit 重新生成）
```
